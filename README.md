# REAS
Real estate agent simulator (UE Editor Utility Widget)

Инструмент для редактора Unreal Engine, предназначенный для генерации зданий и сопутствующих инструментов осмотра на основе данных из JSON-файла.

## 📋 Описание

Проект представляет собой **Editor Utility Widget (EUW)**, который автоматизирует процесс создания многоэтажного здания с возможностью его последующего осмотра. Все данные о структуре здания (этажи, квартиры, планировки) загружаются из внешнего JSON-файла, на основе которого формируется `DataTable`, а затем — сам `P_Build` и инструменты навигации по нему.

Инструмент ориентирован на сценарии, где необходимо быстро развернуть в сцене типовое или параметрическое здание по заранее подготовленному описанию, а затем осмотреть его на трёх уровнях детализации:

- 🏙 **Общий план** — здание целиком в контексте окружения;
- 🏢 **Этажи** — поквартирная разбивка конкретного уровня;
- 🚪 **Отдельные квартиры** — внутренняя планировка и наполнение.

## 🚀 Возможности

- Импорт структуры здания из JSON-файла, выбранного через системный диалог.
- Автоматическая генерация `DataTable` на основе загруженных данных.
- Генерация иерархии `P_Build` в текущем уровне.
- Готовые инструменты для осмотра: общий план, поэтажные виды и переход в отдельные квартиры.
- Минималистичный интерфейс из двух кнопок.

## 🖥 Интерфейс

Editor Utility Widget содержит всего **две кнопки**:

| Кнопка        | Состояние                                              | Действие                                                                 |
| ------------- | ------------------------------------------------------ | ------------------------------------------------------------------------ |
| **Load .json file** | Всегда активна                                         | Открывает системный диалог выбора `.json`-файла с описанием здания       |
| **Build**     | Активируется только после успешной загрузки JSON       | Формирует `DataTable` и генерирует `P_Build` в уровне              |

Логика работы кнопки **Build** заблокирована до тех пор, пока JSON не будет успешно прочитан и провалидирован. Это исключает генерацию здания по некорректным или отсутствующим данным.

## 🔄 Пайплайн работы

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────────┐
│  Load JSON   │ → │  Парсинг &   │ → │  DataTable   │ → │  Генерация       │
│ (файл с диска)│   │  валидация   │   │  (структура) │   │  Building Pawn   │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────────────┘
                                                                  │
                                                                  ▼
                                           ┌──────────────────────────────────────┐
                                           │  Инструменты осмотра:                │
                                           │  • Общий план                        │
                                           │  • Этажи                             │
                                           │  • Отдельные квартиры                │
                                           └──────────────────────────────────────┘
```

## 📂 Структура JSON

JSON-файл описывает здание: этажность, перечень квартир, их метражи и прочие атрибуты, необходимые для наполнения `DataTable`.

> Точная схема JSON определяется используемой `Struct`-структурой `DataTable`. Пример структуры приведён в папке `Docs/` (при наличии).

## 🛠 Требования

- Unreal Engine 5.x
- Включённый плагин **Editor Scripting Utilities**
- Editor Utility Widget, размещённый в проекте (Content Browser → Editor Utilities → Editor Utility Widget)

## ⚙️ Установка и запуск

1. Склонируйте репозиторий в папку `Plugins/` или в корень проекта.
2. Откройте проект в Unreal Engine.
3. Убедитесь, что включены **Editor Scripting Utilities**.
4. Найдите Editor Utility Widget в Content Browser и запустите его (**Run**).
5. Нажмите **Load JSON** и выберите файл описания здания.
6. После успешной загрузки станет активна кнопка **Build** — нажмите её для генерации `DataTable` и `Building Pawn`.
7. Используйте встроенные инструменты осмотра для переключения между общим планом, этажами и отдельными квартирами.
